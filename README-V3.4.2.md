# LIVE MUSIC V3.4.2 — Catálogo, Álbuns e Playlists

## Novidades
- Catálogo atualizado ao voltar para o aplicativo e por Realtime do Supabase.
- Álbuns agrupados com capa, artista, faixas e reprodução completa.
- Playlists pessoais: criar, adicionar/remover músicas, excluir e reproduzir.
- Sincronização entre celular e computador pela conta do usuário.

## Instalação
1. Copie o arquivo `.env` da versão anterior.
2. Execute `supabase/07_v342_catalog_albums_playlists.sql` no SQL Editor.
3. Execute `npm install` e `npm run dev`.
