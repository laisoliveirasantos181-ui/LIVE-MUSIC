# LIVE MUSIC V3.5.5 — Experiência Premium

Versão de acabamento da série V3.5.

## Novidades

- mini player mobile com capa do álbum, título, artista, play/pause, próxima faixa e progresso;
- página dedicada para cada álbum;
- página dedicada para cada gênero;
- Home organizada em prateleiras por gênero;
- navegação sem recarregar o player;
- todos os recursos da V3.5.4 preservados.

## Instalação

1. Copie o arquivo `.env` da versão anterior.
2. Execute `npm install`.
3. Execute `npm run dev`.

Não há SQL novo nesta versão.
